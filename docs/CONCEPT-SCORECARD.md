# Ghost Kitchen Concept Evaluation Scorecard

**Status:** Working evaluation framework
**Version:** 0.1
**Date:** 2026-08-31

## Purpose

Evaluate candidate prepared-food concepts for the first Ghost Kitchen pilot without prematurely selecting a brand.

## Scoring

Score each criterion from **1 (poor)** to **5 (excellent)**. Weight the criteria as shown. A score is a decision aid, not proof of commercial viability.

| Criterion | Weight |
|---|---:|
| Delivery quality after 20–40 minutes | 15% |
| Food-cost potential | 15% |
| Prep simplicity / repeatability | 12% |
| Equipment burden | 10% |
| AOV / bundle potential | 10% |
| Ingredient overlap / purchasing efficiency | 8% |
| Speed of production | 8% |
| Repeat-purchase potential | 8% |
| Local market demand | 6% |
| Differentiation / brandability | 4% |
| Waste / shelf-life profile | 4% |
| Training simplicity | 4% |
| **Total** | **100%** |

## Candidate families

Initial candidates from the Delivery Template remain research candidates:

- burgers
- chicken
- Asian street food
- healthy/protein bowls
- loaded fries/sides
- dessert-focused concepts

The current framework does **not** approve any of these for franchising.

## Evidence required

Each score should eventually be supported by one or more of:

- supplier/ingredient quotes
- recipe-level costing
- competitor research
- delivery/packaging testing
- kitchen time studies
- customer testing
- pilot sales data
- platform/order data where available

## Disqualifiers

A concept should not proceed to pilot merely because it scores well overall. Stop and investigate if it has:

- unresolved food-safety or regulatory constraints
- unacceptable delivery quality
- equipment requirements inconsistent with the template
- structurally weak contribution margin
- excessive preparation complexity
- severe ingredient waste
- inability to standardise quality
- dependence on unvalidated demand assumptions

## Pilot selection gate

The preferred pilot is the concept with the strongest combination of economics, operational simplicity, delivery resilience and repeatability — not necessarily the concept with the highest theoretical revenue.

Final selection requires evidence review and explicit decision logging.
