## Minimum physical-test set

To avoid testing every catalogue option, start with the smallest format set that exercises materially different delivery behaviours across the three candidate concepts.

### Candidate P1 — compact burger clamshell
Purpose:
- burgers/chicken single-item test;
- heat/steam retention;
- bun texture and grease resistance.

Target family:
- 6-inch sugarcane or comparable burger clamshell.

Current public-reference band from refreshed examples: approximately A$0.12–A$0.24 each before landed-cost validation.

### Candidate P2 — larger single-compartment meal clamshell
Purpose:
- chicken + side;
- Asian street-food mains;
- larger mixed meals where separation is not essential.

Target family:
- approximately 900–1200 ml / 8–9-inch clamshell.

Current public-reference examples: approximately A$0.19–A$0.32 each before landed-cost validation.

### Candidate P3 — compartment meal clamshell
Purpose:
- burger/chicken + chips separation;
- protein bowl component separation where appropriate;
- test whether compartmenting reduces texture degradation enough to justify added cost/volume.

Target family:
- 2- or 3-compartment sugarcane clamshell.

Current public-reference examples: approximately A$0.19–A$0.44 each before landed-cost validation.

### Candidate P4 — paperboard/corrugated box
Purpose:
- compare venting and presentation against fibre clamshells;
- useful for burger/chicken concepts where trapped steam may be a quality risk.

Current public-reference examples: approximately A$0.24–A$0.42 each before landed-cost validation.

## Required physical evidence record

For each tested exact SKU record:
1. supplier;
2. exact SKU/product name;
3. material and dimensions/capacity;
4. carton quantity;
5. invoice/quote/public price source and capture date;
6. GST treatment;
7. freight/delivery cost and delivery threshold actually applicable;
8. quantity used in representative pack-out;
9. bag/seal/label/napkin/cutlery additions;
10. total packaging cost per representative order;
11. pack time;
12. 20-minute hold result;
13. 30-minute hold result;
14. 40-minute hold result;
15. leakage;
16. condensation;
17. temperature observations;
18. texture observations;
19. presentation observations;
20. pass/fail/remake outcome.

Only after the exact applicable landed cost and pack-out are validated may the packaging numeric input be considered for `VERIFIED_PROJECT`. Physical suitability requires separate observed evidence.

## Selection rule

Do not select the cheapest box by catalogue price. Advance an exact packaging SKU only when it is acceptable on:
- physical delivery resilience;
- food safety suitability;
- operational pack time;
- landed unit cost;
- availability/reorder practicality;
- compatibility with representative order.

If those facts are unavailable, retain `UNKNOWN` or `PUBLIC_REFERENCE` as appropriate.
